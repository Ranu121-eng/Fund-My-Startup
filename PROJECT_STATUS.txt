IMMEDIATE — TO RUN THE PROJECT
------------------------------
1. Open terminal in:  c:\Users\dell\Desktop\FundMyStartup\backend

2. Run setup (first time only):
      python setup.py
   Enter your MySQL root password when asked.

3. Start the server:
      python manage.py runserver
   OR double-click: backend\run_server.bat

4. Open in browser:
      http://127.0.0.1:8000/frontend/index.html

5. Test full workflow:
   a. Register a startup (with PDF/JPG documents)
   b. Register an investor (with documents)
   c. Login as Admin → approve both accounts
   d. Login as investor → make investment offer
   e. Login as startup → accept offer

DEFAULT LOGIN CREDENTIALS
-------------------------
Platform Admin (Login page → select "Admin"):
   Email:    admin@fundmystartup.com
   Password: Admin@123

Django Admin (http://127.0.0.1:8000/admin/):
   Username: admin
   Password: Admin@123

IF SERVER WON'T START
---------------------
- Check MySQL is running (Services → MySQL80)
- Check .env file exists in backend/ with correct DB_PASSWORD
- Run: python check_django.py  (must show Django 5.2+)
- Run: pip install -r requirements.txt --upgrade

IF ADMIN PAGE SHOWS "super object" ERROR
---------------------------------------
- Stop all running servers (Ctrl+C)
- Run: pip install "Django>=5.2,<6.0"
- Restart: python manage.py runserver
